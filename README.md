# 浙里学 · 浙江高中学习工作台

面向浙江高中生的数学、物理、化学与技术学习网站。技术覆盖信息技术和通用技术。

## 功能

- 40 个核心专题，四科各 10 个；技术按信息 5 个、通用 5 个组织。
- 每专题有知识梳理、关键关系、易错提醒、原创例题与分步解析、原创单选练习。
- 13 份高考、选考、联考及官方评析资料索引，注明来源和实际版本。
- 知识点搜索、学科与年级筛选、收藏、掌握标记。
- 即时判题；答错后自动进入错题本，再次答对后移出。
- 学习计划、每日练习统计、连续学习记录、25 分钟专注计时。
- 学习记录导出及手机布局。

这是首批核心专题内容，不是完整教材或完整历年试题库。年级为建议学习阶段；不同学校、教材版本进度可能不同。所有站内题目为原创，考试原卷通过外部来源访问。部分第三方资料可能要求登录或会员。

## 本地运行

需要 Node.js 22.12+。

```sh
npm ci
npm run dev
npm run build
npm run preview
```

## 发布

推送到 `main` 后，GitHub Actions 自动构建并发布到 GitHub Pages。
仓库 Settings → Pages 的来源需选择 GitHub Actions。
网站使用 Hash 导航及相对资源路径，支持 GitHub Pages 项目子路径。

## 内容维护

- `src/data/topics.json`：专题、原创题、答案和解析。
- `src/data/resources.json`：真实考试资料与来源链接。
- `src/App.tsx`：页面与学习交互。
- `src/styles.css`：桌面和手机样式。

原创练习的 `answer` 为从 0 开始的选项索引。新增内容时应独立核算例题和练习，确保单选题仅有一个正确选项。资料来源应注明官方解读、回忆版、网络参考版或第三方转载，不应把半卷标作完整技术卷。

## 数据与隐私

当前版本不需要账号，不运行后台服务。学习记录使用当前浏览器的 localStorage 保存，不跨设备同步。清除浏览器数据会删除记录。可通过“我的学习空间”导出 JSON 记录。
专注计时在网页保持打开时运行；关闭或刷新页面会重置未完成计时，已完成专注时长会保留。
